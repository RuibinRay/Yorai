
## Worked example tokens — YORAI, "Nocturne & Ember" (2026-11-01)

- **Palette** (`css/tokens.css`, every pair tested): espresso #120c09 / espresso-2 #1c1410 / espresso-3 #2a1f18; paper #f3ebe0 / paper-2 #e9ddcc / paper-3 #d9c9b2; ink #1a120d, ink-muted #665649 (5.9:1 on paper), brass-ink #7a5620 (5.6:1), cherry-ink #9f2f2b; on dark: cream #f3ebe0, cream-muted #c4b5a5 (9.7:1), crema #e8c88a (12:1), brass #c4985a (rules), cherry #e0564f (marks only), mist #a7bdb8. Chapter accents: #a7bdb8 → #e0564f → #e2b15c → #ff7a2f → #c88a4e → #e8c88a (all ≥ 5.3:1 on the copy scrim).
- **Type:** Newsreader Display (opsz 72 instance, wght 300–500; italic at 400) for the wordmark, headings, prices, facts and quotes; Newsreader Text (opsz 20 / italic 24) for ledes and tasting notes; Hanken Grotesk Variable for UI with 0.16em tracking on kickers. Pairings now used on the owner's sites: Fraunces + Instrument Sans, Bodoni + Atkinson, Literata + Albert Sans, Newsreader + Hanken Grotesk — pick a different one next time.
- **Journey conventions:** `.jr` root (`overflow-x: clip`) → `.jr__stage` (sticky 100dvh: canvas host, still layers, vignette, progress hairline, hero, `.jr__copy` blocks, rail, pause) → `.jr__space--<key>` spacers with `--len` in vh from `CHAPTERS[].length`; the driver writes `--jt` on the stage, `--pn` on each copy block (`is-near` / `is-current`), `data-chapter` and `--accent` on the stage. Copy block: kicker (accent), h2 at `--t-xl`, one paragraph ≤ 46ch, a note on an accent rule, a progress rule that grows with `--pn`; a radial scrim behind it (`::before`, no blur); enter 8–28 %, leave from 82 %. Phones: bottom-anchored, paragraph clamped to five lines, rail hidden, header tag hidden.
- **Scene conventions (`journey3d.js`):** `Z[]` group offsets, `PAL[]` per-chapter atmosphere (fog, top, dens, sky, ground, sun, dir, sunI, hemiI, exp), `CAM[]` poses in group-local space (a / al / b / bl; b reached at p = 0.72, then the crossing); builders return a Group whose `userData` names the animated parts; `animate(jt, dt)` owns visibility, lazy builds and every loop; `renderAt(jt)` for probes.
- **Components:** chip filter (`aria-pressed`, live count, empty state); cupping-table row (name + method, meta with the process in brass, italic notes, price with unit); bag SVG from `{hue, ink}` with the wordmark, lot name, process line, notes; pin + list pair sharing `aria-pressed` and one `aria-live` panel (pins 28 px on desktop, markers on phones; `nudge` for clusters); native `<dialog>` with `position: fixed; inset: 0; margin: auto`, `.on-paper` on the dialog, focus back to the opener; forms with labels above, `aria-invalid`, `:empty`-hidden errors, mailto + copy-summary, status in text.
- **Settings:** one `yorai:` storage prefix, `motion: auto | calm | full`, `noticeDismissed`; `?tier=`, `?why`; the pause button only when the scene is live and motion is on.
