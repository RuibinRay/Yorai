
## Hit during YORAI — the coffee journey (2026-11-01) — six procedural environments, Three.js + GSAP, no build step

- **A whole chapter rendered as a black frame with a diagonal edge** → background shrubs for the harvest scene were scattered at random angles around the origin, so one sat on the camera path and the camera was inside it → set dressing goes in the half-space behind the subject (`z = −4 − sin(a)·r`), never in a full circle around the origin; shoot the chapter midpoint before judging anything else.
- **The plantation's volcano stood in the middle of the harvest scene** → environments were 46 units apart while the volcano's base radius was 34 → chapter spacing must exceed the largest prop's reach, and visibility is by chapter index (current, next during the fog crossing, previous for the first 10 %), not by distance.
- **Shrubs rendered as faceted boulders** → `IcosahedronGeometry` is non-indexed, so vertex jitter gave per-face normals → when jittering vertices, start from an indexed `SphereGeometry` so the shading stays smooth; and the near rows needed leaf cards on top before they read as foliage at all.
- **The coffee rows skipped the row next to the aisle** → `x = (row + (row ≥ 0 ? 0.5 : −0.5)) · pitch` has no −0.5·pitch row → write row positions as `(k + 0.5) · pitch` for k in [−n, n).
- **Beans the size of potatoes on the drying beds** → a radius chosen for visibility, never compared with the bed (2.2 m wide) → scale every prop against one known object in the scene (the bed, the cup) before placing hundreds of it; the bulk of the beans became a procedural texture and the instanced layer dropped to 3 cm.
- **Screenshots showed the previous chapter at every stop — for an hour** → two separate causes: the software GPU presents frames late, so the compositor's image lags the scene; and the GSAP scrub needs several rAF frames to settle, which take seconds under SwiftShader → the probe renders synchronously through a `renderAt(jt)` hook and screenshots the canvas's `toDataURL()`; the Costa Rica lesson "probes lie" was already in this file and should have been the first suspect.
- **A chapter check read `chapter 0` after an instant scroll to chapter 1** → the scroll event was queued behind a WebGL frame on the lab's main thread → probes wait for the driver's own state (`waitForFunction` on `data-chapter`), never a fixed timeout.
- **A `[hidden]` button stayed visible** → `.btn { display: inline-flex }` beats the UA's `[hidden]` rule → `[hidden] { display: none !important }` at the top of every stylesheet.
- **The motion notice's second button had invisible text** → `.btn--ghost` carried the dark-surface foreground onto a paper pill → button variants are scoped per surface (`.on-paper .btn--ghost`, `.motion-notice .btn--ghost`), and every surface that hosts buttons gets a screenshot.
- **The reserve dialog's kicker failed contrast** → `.on-paper .kicker` only applied inside sections; the dialog lives outside them → dialogs carry the surface class too (`class="dlg on-paper"`).
- **`aria-label` on a `<span>` (prohibited) and on the brand link (name did not contain the visible text)** → a visually hidden span for the wordmark, and no `aria-label` where the visible text is the name.
- **Clustered map pins failed target-size (22.8 px clear)** → three regions 16–25 px apart at 28–44 px targets → a `nudge` in map units in the data for display only, 28 px targets on desktop, and markers (not buttons) under 900 px where the list is the control.
- **Mobile LCP 4.0 s with a text LCP element** → the hero intro split the wordmark into letters (a new element, painted at opacity 0) after the module graph loaded → never remove or re-create the LCP element; animate it as one element from opacity > 0. Still 3.4 s afterwards: the font swap on the wordmark is the remaining suspect.
- **305 KB of fonts for a wordmark and headings** → the full opsz + wght variable files → `fonttools varLib.instancer` into the four faces the site uses (display opsz 72 with wght 300–500, text opsz 20/24 at 400): 117 KB. Subsetting glyphs alone saved nothing; the axes were the weight.
- **A tree-shaken three.js bundle saved 20 %, not 60 %** → `WebGLRenderer` pulls in most of the library → not worth a build step for an owner who edits on GitHub; vendored minified module + importmap kept, the attempt recorded in the README.
- **Playwright's first Tab did not reach the skip link** → after clicks, the sequential-focus starting point follows the last focused element even after `blur()` → test the tab order on a fresh navigation.
